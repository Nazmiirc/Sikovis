# SIKOVIS

**A mobile app that makes motorcycle service booking easier and faster.**

SIKOVIS lets motorcycle owners in Bogor book workshop services from their phone, instead of calling the workshop or queuing in person.

> Built as a 1-month team project (April to May 2025) by a team of three: two developers and one UI/UX designer.

## The Problem

User research showed that motorcycle service booking in Bogor is still mostly manual:

- **Inefficient booking.** Customers book by phone or by visiting the workshop, which leads to miscommunication.
- **Long queues and uncertain service time.** Customers arrive without knowing whether the workshop is full or a technician is available.
- **Unclear service information.** Most workshops do not offer a place to see service types, schedule availability, estimated cost, or service duration.
- **No reminders.** Many customers forget or miss their scheduled service.

## The Solution

SIKOVIS is a mobile app built around three user needs found in the research: efficiency, clear information, and convenience.

## Features

- Browse and search available motorcycle services
- Book a service appointment from the app
- Service information in one place
- User profile and settings

## Getting Started

### Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install) (Dart SDK 3.7 or newer)
- An Android emulator, iOS simulator, or a physical device

### Run the app

```bash
# 1. Clone the repository
git clone https://github.com/Nazmiirc/Sikovis.git
cd Sikovis

# 2. Install dependencies
flutter pub get

# 3. Run on a connected device or emulator
flutter run
```
